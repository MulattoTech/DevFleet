## Remote execution environment normalization
Remote Desktop Commander processes have previously lacked `COMPUTERNAME` and `ProgramFiles(x86)`. This is an execution-context quirk, not permission failure. For RDC-only shells, set missing values transiently from Windows APIs:
`$env:COMPUTERNAME=[Environment]::MachineName`
`if(-not ${env:ProgramFiles(x86)}){${env:ProgramFiles(x86)}=[Environment]::GetFolderPath([Environment+SpecialFolder]::ProgramFilesX86)}`
Do not persist those environment changes system-wide.
